ENGAJA AI STUDIO V2.0
Publique todos os arquivos juntos em hospedagem estática HTTPS (ex.: Netlify Drop). Abra o endereço no Chrome Android e instale pelo menu. Offline após primeira visita. Histórico IndexedDB local, sem sincronização; limpar dados apaga projetos. Exportação vídeo depende de MediaRecorder; WebM pode exigir conversão para MP4. Mantenha tela aberta. Áudio deve ser autorizado pelo usuário. IA: servidor HTTPS com CORS, POST multipart image (arquivo) e briefing (JSON), resposta JSON {title,caption,hashtags:[...]}. Nenhum servidor ou chave incluído. Tendências: links externos, não ranking automático. Compartilhamento via Web Share, não publicação automática. GIF animado não implementado. Teste no aparelho antes de uso.
